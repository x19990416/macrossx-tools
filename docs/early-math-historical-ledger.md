# 幼升小数学：历史题目台账

本文件是**题型研究与改编台账，不是可作答题库**。第一批逐图核对 PDF 外层 1–30；第二、三批已核对 31–100 的图面并登记候选规则。材料是历史整理题集，学校官方属性、原题年份及再发布授权均未确认。不复制题图，不把下表候选答案当作官方答案。

## 资料定位与口径

- **PDF**：用户提供的《上实机考题1-9题汇总》《上实机考题10-20题汇总》《上实机考题21-30题汇总》及外层编号 31–100 的七个分包。页码从各分包第一页起算。稳定 ID 为 `hist-q001` 至 `hist-q100`，对应 PDF **外层题号**，不跟随图内旧编号。
- **公开题录**：Excel 工作表「2017公开图文题录_1-30」及其[图文解析页](https://www.sohu.com/a/134803349_391521)。表内的「题录」指该表条目；题型与解析细节相合不等于已验证网页原图和 PDF 完全一致。未看到完整独立答案册。
- **核解口径**：「图解」表示按 PDF 可见图形独立推得的候选；「旁证」只表示公开解析答案与候选一致；「待核」表示图面、规则或跨源映射还不能确认。本批没有授权发布原图的条目。相似题归入同一原创模板，不直接标作完全重复。
- **去向**：P1 是规律和分类，P3 是拼合和空间变换，P4 是代换与条件推理；「仅索引」指暂不按原题出题。能力记录系统暂缓，不影响题型整理。
