# 幼升小数学工具：内容整合与实施路线

- 状态：规划内玩法均已实现并通过本地浏览器回归，发布状态以 GitHub Actions 为准；以 2026-11-13 为资料盘点基线。
- 目标：把现有「幼升小数学游戏」扩成能 **看示例 → 动手试 → 说理由 → 换情境再试** 的中文工具。
- 现有入口：`/macrossx-tools/#/early-math`。保留原有 3 个小游戏、4 张生活任务卡和 7 道进阶挑战；口算练习册不变。
- 内容原则：整合所有可辨识的数学题型与教学方法，不承诺原样上线每一道历史题。每条资料都要有去向：游戏、亲子卡、进阶题、家长资料索引、重复或待核。不做招生预测、官方模拟卷、排名或限时闯关。

## 2. 内容总蓝图

三类入口保持不变，家长区说明培养目标、可观察表现与生活迁移，来源保留在内部资料和台账中。难度标为「入门 / 进阶 / 挑战」，按孩子能否读懂规则和操作前置能力分层，不按年级硬性分配。

| 内容线                     | 入门                                    | 进阶 / 挑战                                                | 生活迁移与落点                                         |
| -------------------------- | --------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------ |
| 找规律（P1、P3）           | 串手链：重复单个形状组                  | 两种属性按各自周期变化；行列缺项、多图组合                 | 用积木再用拍手复现；动手小游戏、进阶挑战               |
| 分类与排除（P1、P4）       | 对同一组图形先按形状、再按条纹换规则    | 同时满足两个条件、找缺少的图形；开放题允许多种合理分法     | 按种类或盒子大小收玩具；小游戏、亲子卡                 |
| 数量、数轴与代换（P2、P4） | 一一对应、公平分配；等距格上逐步走      | 给起终点反推方向或步数；区分按顺序编码和数值加减；图形等式 | 摆餐具、地面跳格、按图例拿物品；小游戏、进阶题         |
| 平面与空间（P3）           | 用纸片/吸管拼合、沿格线平移、四分之一转 | 同时跟踪位置与朝向、行列叠加、分层数立体方块               | 拼图、搬积木、观察遮挡；小游戏、亲子卡                 |
| 测量与关系（P4）           | 从同一端比较长短、从长到短排序          | 比较折线的单位格长度、用天平关系推理；观察线索列可能性     | 排铅笔、量桌面、称物品；亲子卡、进阶挑战               |
| 听规则与记忆（P5，可选）   | 不隐藏示例，先练按顺序摆图与复述规则    | 主动点「准备好了」后隐藏，再按顺序复原；允许重看，不限时   | 看摆放顺序后复盘；独立可选模式，不把记忆和数学推理混判 |

## 3. 实施顺序与逐阶段验收

每个阶段独立验收，再进下一阶段。标记为「可选」的内容先以小样验证价值，不承诺复制原来的机考机制。

- [x] **P0a｜资料盘点。** 已整理工作簿、公开来源和 10 份 PDF 的覆盖范围，初览全部页。
- [x] **P0b｜建 100 项题目台账。** 先用 1–30 校准与 Excel 的匹配方法，再分 31–69、70–100 两批。逐题检查图文完整性，标主/次题型、候选规则、来源答案与独立推导、重复关系及上线去向。验收：外层 1–100 各有一条记录，错位有例证，资料不足明确标记，不用猜测答案补齐。
- [x] **P1｜分类小侦探 + 串手链升级。** 分类第一轮挑圆形，第二轮用同一组图改挑带条纹的；串手链保留原版，增设一个形状与颜色独立变化的关卡。验收：漏选和多选都有可操作的提示；颜色同时有名称或纹理提示；切换、重置不带入旧作答。用玩具分类或拍手节奏检验迁移。
- [x] **P2｜跳格子地图。** 三步：看一次演示 → 从给定起点逐格移动 → 凭起终点反推。先 0–8 等距格，不要求列式；左右移动都可练。验收：起点不算一步、不能越界、错方向和错步数可区分；键盘可走全流程，手机 320px 不溢出。
- [x] **P3｜空间与图形。** 依次交付「拼图工坊」「格子转转」「积木楼梯」；吸管拼三角形和正方形先走亲子卡。验收：拼合与重叠保留规则明确；平移与转向分别判定；立体计数明确遮挡/承托条件，核对分层示意。
- [x] **P4｜测量、符号与条件推理。** 交付「铅笔排队/格线比长」「图形密码」「根据线索找物品」；加入比较轻重的进阶卡。验收：编码按顺序读、等式按数值算，不混在一道入门题里；所有封闭题校验唯一答案或完整答案集合，开放题不强判。
- [x] **P5｜记忆与先看再做（可选）。** 做独立的排序记忆小样；先确认孩子理解规则，再进入短序列记忆。验收：无倒计时、可重看或跳过，不让短时记忆影响其他关卡的反馈。若没有必要，资料留索引即完成处理。
- [x] **P6｜全量回查和本地发布前验收。** 按来源盘点中每一类检查去向，确认所有数学题型已覆盖或有记录解释为何延后/不收录；再验收正式构建、首页入口、旧游戏、主题、手机和生产子路径。只有用户明确要求时才提交、推送和发布。

**实际执行顺序：** 先用已明确的概念做 P1、P2 原创玩法，不依赖历史题答案。P0b 已登记 1–100，仍保留未能确认的原题答案；P3–P5 原创玩法已补齐。

## 4. 台账、实现和发布规则

- **内部台账字段：** 资料 ID、分包、页码、外层题号、图内题号（如有）、关联网页及序号、主/次题型、完整状态、原答案出处、独立核解状态、授权状态、重复 ID、转化方式、目标阶段。状态区分「待阅」「题面可用」「待核答案」「有分歧」「可做原创」「仅索引」。完整原件和中间裁图留在私有位置；仓库只放公共来源信息、必要的自写摘要及原创题材。
- **公开练习字段：** 稳定 ID、能力标签、难度、原创题面、可访问的图形描述、交互规则、提示、反馈、参考思路、换情境任务。来源只保留在内部资料和台账，不显示在游戏页面。题目答案按规则生成或独立复核；原题没有答案时，不把猜测当成题库答案。授权不明确不转载，且不给未核题挂「可作答」标签。
- **代码落点：** 在现有 `src/tools/early-math/` 新增本工具的数据和专用组件。新小游戏逻辑独立拆分，页面只负责入口与切换；生活任务与进阶题复用 `TaskCards.vue`。用原创 SVG、语义化按钮和文字辅助；所有练习本地运行，不热链题图、不上传作答、不引入后端。
- **每阶段完成定义：** 内容与提示各走一轮人工审阅；类型、ESLint、改动文件格式、`git diff --check` 与生产构建通过；浏览器读写状态、错误反馈、撤回/重置、键盘、浅深色、320px 与子路径实际验证。无复制/下载的玩法不额外增加按钮；未来若加打印需另验排版。把验证结果区分为构建、浏览器和实际孩子试用，不把一种代替另一种。

### 能力记录的预留设计

现有小游戏使用稳定的能力 ID 与能力领域，并展示「培养目标—观察表现—生活迁移」。一个游戏可供观察多项表现，例如基础串珠与双规律关分开看，跳格子的顺推与反推也分开看。

能力评估记录当前暂缓。未来如增加记录功能，记录应关联能力 ID、活动及关卡，并区分「未观察」「提示后做到」「独立做到」「换个情境也能做到」。保留当时的具体表现或提示，不把游戏一次判对、用时或完成率直接换算成能力等级。本轮只添加观察指标，不收集或保存儿童数据。

## 6. 最终覆盖与验证

- **历史 PDF 1–100：** 保留台账逐项去向。序列与颜色规律转串珠；叠合、变换、空间计数转拼图工坊、格子转转、积木楼梯；长度、重量、符号和约束转对应练习；多种合理分类作为开放亲子卡。图面含混或只有素材的条目只保留索引。这不是 100 道原题的网页复刻。
- **面谈与截图：** 数轴转跳格子，吸管搭图转亲子卡，同类/不同类转分类小侦探。短序列记忆是单独的可选游戏，不计时并允许重看。未知规则的骰子题、快速钟面、语英体育等条目只留资料索引。
- **本地验收：** 生产子路径加载、首页往返、13 个游戏入口、新游戏两轮与原有玩法回归、错误输入、撤回和重置、键盘激活、320px、深色样式与控制台检查。尚未做真实儿童试用。
